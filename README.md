# Codinglands website

Static public company website for CODINGLANDS S.R.L., intended for GitHub Pages and the `codinglands.com` domain. Open `index.html` directly or serve this directory with a local HTTP server. No build step or dependencies are required.

The site contains public company registration information and a business contact email. It uses no analytics, cookies, third-party scripts, or forms.

Company identity and registered office were checked against the ONRC registration certificate issued on 9 June 2026. The site does not include the company’s private documents, tax filings, banking details, or D-U-N-S correspondence.
